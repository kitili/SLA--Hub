# Addition

## Adding numbers not exceeding 999

Numbers can be added horizontally or vertically. Addition is done by considering the place value of each digit in a number.

## Adding numbers horizontally without regrouping

Numbers are added starting from the right to the left.

Divide 12 pages by 3.

Divide 36 by 6.
