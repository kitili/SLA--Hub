# Introduction

This is the first book in a series of two books for Writing in Primary Schools.The book is intended to help a Standard One pupil develop writing competencies necessary for effective learning. It consists of ten chapters. Each chapter contains activities and exercises which enable the pupil to acquire basic writing skills. It is expected that these exercises will enable the pupil to write letters of the English alphabet, some keywords, sentences, paragraphs and short stories.
