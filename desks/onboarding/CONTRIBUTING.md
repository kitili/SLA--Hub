# Contributing

Internal project for Silverleaf Academy. Thank you for helping improve the onboarding hub.

## Getting started

1. Clone the repository and follow [README.md](./README.md)
2. Create a branch from `main`
3. Make focused changes with clear commit messages
4. Run `npm run verify` before opening a pull request

## Guidelines

- Match existing code style and naming conventions
- Keep changes scoped — one feature or fix per PR
- Do not commit `.env`, `documents/`, or `node_modules/`
- Update `hub-content.json` and `onboardingData.js` together when changing sections
- HR-facing copy should use UK English

## Pull requests

Use the PR template and include:

- What changed and why
- How you tested it
- Screenshots for UI changes

## Questions

Contact the project maintainer or HR/IT lead.
